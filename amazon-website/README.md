# Amazon.in Clone (Responsive Website)

A responsive clone of the Amazon.in home page built with only **HTML, CSS and JavaScript**.

## Features
- Fully responsive layout (mobile, tablet, desktop)
- Auto-playing hero slider with arrows, dots and swipe support
- Product cards and horizontally scrolling product rows
- Search bar with category selector
- Scrollable navigation bar on small screens
- Responsive footer and "Back to top" button

## Project Structure
```
amazon-website/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
└── README.md
```

## How to Run
Open `index.html` in any browser. No installation needed.

## Live Demo (GitHub Pages)
1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under *Source* choose the `main` branch and the `/ (root)` folder, then Save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Tech Used
HTML5 · CSS3 (Flexbox, Grid, Media Queries) · Vanilla JavaScript
Icons: Font Awesome (CDN)
